## Metrics workflow

Profile card is generated by the **Metrics** GitHub Action (forked [lowlighter/metrics](https://github.com/lowlighter/metrics) image published from this repo).

### Failed runs / Bad credentials

Hourly Metrics runs fail with `HttpError: Bad credentials` when the `METRICS_TOKEN` repository secret is missing, expired, or revoked.

1. Create a [classic personal access token](https://github.com/settings/tokens) (no scopes required for public metrics; add `repo` if you want private contributions included).
2. Update **Settings → Secrets and variables → Actions → `METRICS_TOKEN`**.
3. Re-run **Actions → Metrics → Run workflow**.

Activity-plugin crashes on truncated GitHub `PushEvent` payloads are already handled by `.github/metrics/activity-null-users.patch` when the metrics image is published.
